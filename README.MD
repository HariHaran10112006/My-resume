# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application built using React and Redux.

Users can browse different categories of houseplants, view plant details, add plants to a shopping cart, update quantities, remove plants, and view the total cart amount.

## Features

- Paradise Nursery landing page
- Company information
- Get Started button
- Three plant categories
- Six plants per category
- Plant images, names and prices
- Add to Cart functionality
- Dynamic cart item count
- Shopping cart management
- Increase and decrease quantity
- Delete items
- Total cost calculation
- Checkout button
- Continue Shopping button

## Technologies

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
